## Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

CIGA Interaction Studio may connect to external services when the user explicitly configures or enables those integrations, including StreamElements, VTube Studio, and CIGAIS services.

## Signing scope

Only CIGA Interaction Studio binaries built from the source code in this repository will be submitted for signing.

All signed releases are built from the project's own source code and build configuration.
